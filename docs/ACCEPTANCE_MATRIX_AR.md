# مصفوفة وظائف Sport Performance 3.0

| المجال | ما تم تضمينه في الحزمة | نوع التحقق |
|---|---|---|
| الهوية والواجهة | PWA متجاوب، عربي/فرنسي/إنجليزي، RTL/LTR، شعار تطبيق/مؤسسة/علامة مائية | فحص بناء وملفات ثابتة |
| الحسابات | مالك منصة، مدير مؤسسة، إدارة، مدرب؛ تسجيل معلّق وموافقات متدرجة | مراجعة SQL/JS؛ يتطلب اختبار مستخدمين حيًا |
| عزل المؤسسات | RLS، current institution، مفاتيح مركبة، سياسات Storage | اختبارات SQL بنيوية؛ يتطلب اختبار RLS حيًا |
| السنوات | سنة جارية، أرشفة، عرض/تصدير السنوات القديمة، منع التعديل | SQL triggers وواجهة؛ يتطلب اختبار قاعدة حيًا |
| التلاميذ | رقم يدوي، أقسام، تعديل وأرشفة، بحث، لصق جماعي ومعاينة | اختبارات parser وSQL؛ يتطلب اختبار CSV حيًا |
| الحصص | اختيار درس، مدرب ووقت بداية/نهاية ومدة، إغلاق مرة واحدة | فحص كود وقيود SQL؛ يتطلب اختبار جلسة حيًا |
| الحضور | حاضر/غائب/متأخر، أسباب الغياب، إدخال أرقام جماعي، منع التكرار | اختبارات parser وقيود SQL؛ يتطلب اختبار عدة مدربين حيًا |
| التأهيل | خمس غيابات متتالية، عودة، حصتان فعليتان مكتملتان، معالجة وتاريخ | اختبار بنيوي للدوال/المشغلات؛ يتطلب اختبار سيناريو حيًا |
| الاختبارات | NAVETTE 20m، Pompes، Abdominaux، Barre fixe/Perfix، إضافة وتعطيل | فحص المخطط والواجهة |
| BARÈME | إدخال/لصق ومعاينة، إصدار وتاريخ سريان، عدم اختراع العلامات، إصدار ثابت | اختبارات parser وقيود SQL؛ يتطلب إدخال سلم المؤسسة الحقيقي |
| النتائج | أداء خام، مدة، سرعة/تحويلات، معدل تكرار، استيراد ذري وتصحيح محمي | اختبارات الدوال وSQL البنيوية؛ يتطلب بيانات اختبار حيّة |
| القياسات | وزن، طول، BMI، سجل واتجاه | فحص كود ومخطط |
| الملاحظات | ملاحظات المؤسسة وكراس خاص لكل مدرب ولكل سنة | RLS بنيوي؛ يتطلب اختبار حسابين حيًا |
| المنشآت | منشآت وتجهيزات مستقلة لكل مؤسسة | RLS بنيوي وواجهة |
| الخطط والملفات | خطط حصص وملفات PDF/Word/Excel/TXT في Storage خاص | فحص إعدادات؛ يتطلب اختبار رفع فعلي |
| التقارير | ملخص أقسام ونسب حضور وملخص علامات، CSV، طباعة، وتصدير السنة كاملة XLSX | فحص واجهة؛ يتطلب مراجعة ملفات Excel الناتجة |

**مهم:** المصفوفة تصف الكود المضمّن، ولا تعني أن خدمة Supabase أو Cloudflare التابعة للمستخدم قد تم اختبارها أو نشرها من هذه البيئة.
